# 在月面搭建一座电波塔

> 「如果没有人听见，电波还存在吗？」
>
> ——某本忘了名字的科幻小说

这个问题我想了很久。后来觉得，**存在**。因为发射这个动作本身，就已经是对抗遗忘的方式了。

## 为什么还要做个人网站

社交平台很好用，发一张图三秒钟，收获十几个赞。但那些东西不完全属于我：排序不属于我，字体不属于我，背景音乐不属于我，连「这条动态会不会被折叠」都不属于我。

所以我想有一块自己的地方。不用很大，能放下一张书桌、一盏台灯、一台旧显示器就够了。墙上可以贴海报，角落可以堆纸箱，门牌上写着自己取的名字。

这个站叫 **星屑電波塔**。名字是在凌晨两点想到的，当时窗外有一点点雨，我在听《鳥の詩》。「星屑」是星星的碎屑，「電波塔」是发射信号的东西。合起来就是：一座用星星碎片搭起来的、不停向宇宙发送无用信号的小塔。

## 想要保留的东西

下面这些，是我对「古早二次元个人站」的记忆清单：

- 进站时叮叮当当的 **背景音乐**，而且一定要有开关
- 88×31 的 **友情链接徽章**，互相贴在页脚
- 像素字体的 **访问计数器**，数字还会一位一位地跳
- 用 `[ ]` 包起来的导航，鼠标移上去会反色
- 一行 **跑马灯**，写着「欢迎来到 XXX 的小站」
- 页面底部的「Best viewed at 1024×768」
- 留言板里陌生人的一句「交换链接吗？」
- 还有那些做得歪歪扭扭、但一看就是手写的 **About Me**

我不打算把这些原样复刻成 2003 年，而是把它们放进 2026 年的壳里：能响应式、能暗色模式、能 RSS 订阅，也能在手机上勉勉强强看。

## 技术选择

选 Astro 的原因很朴素：它默认不往页面里塞 JavaScript。博客就是博客，文章读起来应该像文章，而不是一个需要加载 2MB 脚本才能显示文字的网页。

```ts
// 这就是本站大部分「逻辑」的样子
const posts = await getCollection('blog', ({ data }) => !data.draft);
const sorted = posts.sort(
  (a, b) => b.data.date.valueOf() - a.data.date.valueOf()
);
```

页面上的交互（昼夜切换、BGM、搜索、留言板）用原生 TypeScript 写，大概一千行，没有框架，没有状态管理库。够用了。
